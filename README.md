# 地震応答解析Webアプリ

準備中

## 概要
建物の地震時の挙動を、**Webブラウザ上で視覚的に確認できる地震応答解析アプリケーション**です。
建物を複数の質点とばねでモデル化し、質量・剛性・減衰定数といった建物の条件と地震波を入力して地震応答解析を行うことで建物の揺れをアニメーションで確認できます。

## コンセプト
### 「ただ計算結果を出力する」でなく、「建物がどう揺れているのか」を可視化する
学生時代、研究室ではPythonを使って解析や計算を行っていました。今回はあえてPythonを使わず、これまで扱ったことのないプログラミング言語で一つのアプリケーションを完成させることに挑戦しました。

言語にはJavaを選びました。Javaは企業の求人で使用されている例が多く、実際の開発現場でも幅広く利用されていると感じたためです。研究で使っていたPythonとは異なる言語を学ぶことで、特定の言語に依存せず、プログラミングそのものへの理解を深めることも目的としました。

題材には地震応答解析を選びました。研究室で触れていた地震応答解析ソフトに以前から興味があり、既に馴染みのある分野を題材に、数値を計算するだけでなく、計算結果をアニメーション化するところまでを自分で作ったほうが面白いと考えました。

これまで解析結果をアニメーションなどで可視化するものを作った経験がなかったため、単に計算結果を出力するのではなく、実際に建物が動き、解析結果を視覚的に確認できるものを自分で作ることを目指しました。


そこで本アプリでは、**解析計算と可視化を組み合わせることで、地震応答を「数値」だけでなく「動き」として理解できること**を目指しています。

## 使用言語とフレームワーク
* **HTML / CSS / JavaScript**：画面構成や建物の揺れの可視化に使用
* **Java**：地震応答解析の計算処理に使用
* **Spring Boot**：Javaを用いたWebアプリケーションのバックエンド開発に使用
