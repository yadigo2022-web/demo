準備中

## 概要
建物の地震時の挙動を、**Webブラウザ上で視覚的に確認できる地震応答解析アプリケーション**です。
建物を複数の質点とばねでモデル化し、質量・剛性・減衰定数といった建物の条件と地震波を入力して地震応答解析を行うことで建物の揺れをアニメーションで確認できます。

## コンセプト
### 「計算結果を見る」だけでなく、「建物がどう揺れているのか」を理解できる解析ツール

構造解析では、固有周期や応答加速度、変位などの数値を計算することができます。

しかし、数値だけでは、

* 建物のどの部分が大きく揺れているのか
* 地震波によって建物の応答がどのように変化するのか
* 固有振動数や減衰が応答にどのような影響を与えるのか

といった現象を直感的に理解することが難しい場合があります。

そこで本アプリでは、**解析計算と可視化を組み合わせることで、地震応答を「数値」だけでなく「動き」として理解できること**を目指しています。

## 使用言語とフレームワーク
* **Java**：地震応答解析の計算処理を実装
* **HTML / CSS / JavaScript**：解析条件の入力画面や解析結果の表示、建物の揺れの可視化を実装
* **Spring Boot**：Javaを用いたWebアプリケーションのバックエンド開発に使用
