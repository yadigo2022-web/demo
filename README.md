# 地震応答解析Webアプリ

## Webページ
https://demo-efe2.onrender.com/


## 概要
地震時における建物の挙動を、**Webブラウザ上で視覚的に確認できる地震応答解析アプリケーション**です。
建物を複数の質点とばねでモデル化し、質量・剛性・減衰定数といった建物の条件と地震波を入力して地震応答解析を行うことで建物の揺れをアニメーションで確認できます。

## コンセプト
### 「ただ計算結果を出力する」でなく、「建物がどう揺れているのか」を可視化する
学生時代、研究室でPythonを使用して計算を行っていました。今回はあえてPythonを使わず、これまで扱ったことのないプログラミング言語で一つのアプリケーションを完成させることに挑戦しました。

言語にはJavaを選びました。Javaは企業の求人で使用されている例が多く、実際の開発現場でも幅広く利用されていると感じたためです。特定の言語に依存せず、環境や目的に応じて、自ら学びながら開発できる力が大事であると考え、使用経験があるPythonとは異なる言語を用いました。

題材には地震応答解析を選びました。研究室で触れていた地震応答解析ソフトに以前から興味があり、既に馴染みのある分野を題材に、Web上で公開するところまでを作り上げようと考えました。

これまでアニメーションなどで可視化するものを作った経験がなかったため、単に数値として結果を出力するのではなく、実際に建物が動き、解析結果を視覚的に確認できるものにしました。


そこで本アプリでは、**解析計算と可視化を組み合わせることで、地震応答を「動き」として理解できること**を目指しました。

## 作成について
作成期間は約2週間です。作成にあたっては、chatgptを活用して問題やエラーをコードを動かしながら解決して進めました。

## 使用言語とフレームワーク
* **HTML / CSS / JavaScript**：画面構成や建物の揺れの可視化に使用
* **Java**：地震応答解析の計算処理に使用
* **Spring Boot**：Javaを用いたWebアプリケーションのバックエンド開発に使用
