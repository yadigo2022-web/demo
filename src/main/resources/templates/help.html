時刻歴応答解析

時刻歴応答解析とは

時刻歴応答解析（Time History Analysis）は、地震波を時間の経過に沿って建物へ入力し、各時刻における建物の応答を求める解析手法です。


説明はこちらです。

F = ma

x = A sin(ωt)

ω = √(k/m)

モデル化方法

実際の建物は柱や梁、壁など多くの部材で構成されており、 そのままでは建物全体の揺れを理解したり計算したりすることが難しくなります。 そこで、地震応答解析では建物を「質点」と「ばね」を用いた シンプルなモデルに置き換えて解析を行います。

\[ m\ddot{x}+c\dot{x}+kx=f(t) \]

1質点系の時刻歴応答解析

時刻歴応答解析では、運動方程式を解析的に解くことが困難なため、 時間刻み \(\Delta t\) ごとに応答を逐次計算する数値積分法を用います。

本プログラムでは、時刻 \(t_i\) における変位・速度・加速度から、 次時刻 \(t_{i+1}\) の応答を以下の式により求めています。

次時刻の加速度

\[ \ddot{y}_{i+1} = - \frac{ \ddot{y}_{g,i} + 2h\omega \left( \dot{y}_i + \frac{\Delta t}{2}\ddot{y}_i \right) + \omega^2 \left( y_i + \dot{y}_i\Delta t + \frac{\Delta t^2}{4}\ddot{y}_i \right) } { 1 + h\omega\Delta t + \frac{\omega^2\Delta t^2}{4} } \]

次時刻の速度

\[ \dot{y}_{i+1} = \dot{y}_i + \frac{\Delta t}{2} \left( \ddot{y}_i + \ddot{y}_{i+1} \right) \]

次時刻の変位

\[ y_{i+1} = y_i + \dot{y}_i\Delta t + \frac{\Delta t^2}{4} \left( \ddot{y}_i + \ddot{y}_{i+1} \right) \]

この計算を地震波データの全時刻について繰り返すことで、 建物の変位・速度・加速度の時刻歴応答を求めます。

固有値解析

固有値解析

固有値解析（Eigenvalue Analysis）は、構造物が本来もっている振動の性質を求める解析手法です。 固有値解析を行うことで、建物の固有振動数、固有周期、固有モードを求めることができます。

多自由度質点系の自由振動は、次の運動方程式で表されます。

\[ \mathbf{M}\ddot{\mathbf{x}} + \mathbf{K}\mathbf{x} = \mathbf{0} \]

ここで、

  • \(\mathbf{M}\)：質量行列
  • \(\mathbf{K}\)：剛性行列
  • \(\mathbf{x}\)：変位ベクトル

とします。

自由振動の解を

\[ \mathbf{x} = \boldsymbol{\phi} \sin(\omega t) \]

と仮定すると、

\[ \left( \mathbf{K} - \omega^2 \mathbf{M} \right) \boldsymbol{\phi} = \mathbf{0} \]

が得られます。

非自明解が存在する条件より、

\[ \left| \mathbf{K} - \omega^2 \mathbf{M} \right| = 0 \]

を満たす固有値を求めます。

得られた固有値 \(\omega^2\) から、固有円振動数および固有周期は次式で計算されます。

固有円振動数

\[ \omega = \sqrt{\lambda} \]

固有振動数

\[ f = \frac{\omega}{2\pi} \]

固有周期

\[ T = \frac{2\pi}{\omega} \]

また、各固有値に対応する固有ベクトル \(\boldsymbol{\phi}\) は固有モード（モード形状）と呼ばれ、 各振動モードにおける建物の変形形状を表します。

固有値解析によって得られた固有周期および固有モードは、 モード重畳法や応答スペクトル法などの地震応答解析の基礎データとして利用されます。

固有周期とは、物体や構造物が一度揺れ始めたときに、 1回揺れるのにかかる時間のことです。 単位は秒（s）で表されます。 質量が大きいほど揺れはゆっくりになり、固有周期は長くなります。 一方、剛性が大きいほど揺れは速くなり、固有周期は短くなります。 地震では、地面の揺れの周期と建物の固有周期が近いと、 揺れが大きくなる「共振」が起こることがあります。 そのため、建物の安全性を評価するうえで固有周期は非常に重要な指標となります。

\[ T = 2\pi\sqrt{\frac{m}{k}} \]

刺激係数（Participation Factor）

地震時には、すべての固有モードが同じ大きさで励起されるわけではありません。 各モードが地震動によってどの程度励起されるかを表す指標を刺激係数（Participation Factor）といいます。

第 i モードの刺激係数は、次式で求められます。

\[ \Gamma_i = \frac{ \boldsymbol{\phi}_i^{\mathrm{T}} \mathbf{M} \mathbf{r} }{ \boldsymbol{\phi}_i^{\mathrm{T}} \mathbf{M} \boldsymbol{\phi}_i } \]

ここで、

  • \(\Gamma_i\)：第 i モードの刺激係数
  • \(\boldsymbol{\phi}_i\)：第 i モードの固有ベクトル
  • \(\mathbf{M}\)：質量行列
  • \(\mathbf{r}\)：影響ベクトル（通常は全成分が1のベクトル）

とします。

刺激係数が大きいモードほど、地震動による影響を強く受けることを意味します。 一方、刺激係数が小さいモードは、地震応答への寄与が小さくなります。

モード重畳法では、各モードの応答を求めた後、刺激係数を用いて実際の地震応答へ換算します。

各モードの変位は、

\[ \mathbf{u}_i = \Gamma_i \boldsymbol{\phi}_i q_i \]

と表されます。

最終的な構造物の応答は、すべてのモードの応答を重ね合わせることで求められます。

\[ \mathbf{u} = \sum_{i=1}^{n} \Gamma_i \boldsymbol{\phi}_i q_i \]

一般に、低次モードほど刺激係数が大きくなることが多く、構造物の地震応答には第1モードが大きく寄与します。そのため、多くの建物では第1～数モードまでを考慮することで十分な精度が得られます。

有効質量比

\[ \beta_i= \frac{\boldsymbol{\phi}_i^{T}\mathbf{M}\mathbf{1}} {\boldsymbol{\phi}_i^{T}\mathbf{M}\boldsymbol{\phi}_i} \]

\[ M_i^{*}= \frac{\left(\boldsymbol{\phi}_i^{T}\mathbf{M}\mathbf{1}\right)^2} {\boldsymbol{\phi}_i^{T}\mathbf{M}\boldsymbol{\phi}_i} \]

\[ r_i= \frac{M_i^{*}} {\mathbf{1}^{T}\mathbf{M}\mathbf{1}} \times100\% \]
